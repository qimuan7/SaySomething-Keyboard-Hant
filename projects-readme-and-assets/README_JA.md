## 関数：

### 音声認識：

1. **長押しで録音** - シンプルで直感的な録音操作

2. **スマートストップ** - 無音時に自動的に録音を停止。手動操作は不要です。

3. **超高速認識** - 指を離すとアップロード。結果がすぐに表示されます。マルチエンジン対応 - 11種類の主要ASRサービス（クラウド7種類＋ローカル4種類）

4. **ローカルASRモデル** - オフライン音声認識に対応。ネットワーク接続不要でプライバシーを保護します。

5. **AIテキスト後処理** - LLM後処理により認識結果を補正します。


### フローティングボール入力：

1. **クロスインストール方式対応** - あらゆる入力方式で音声入力に対応します。

2. **シームレス統合** - 既存の入力習慣を維持します。

3. **自動挿入** - 認識結果が自動的に挿入されます。

4. **互換モード** - TelegramやTikTokなどの専用アプリに対応します。

5. **視覚的フィードバック** - 録音/処理状況が分かりやすく表示されます。
   

### スマート入力：

1. **AI編集パネル** - 専用の編集インターフェース。音声コマンドでテキスト編集が可能です。

2. **豊富な編集ツール** - カーソル移動、選択、コピー＆ペーストなど、充実した編集機能を搭載。

3. **スマートターゲット選択** - 編集対象（選択テキスト／最後に認識されたテキスト／全文）を自動的に識別。

4. **カスタマイズ可能なキー** - 句読点をカスタマイズ可能。

5. **ペンギン／トンウェン入力方式との連携** - ペンギン／トンウェン入力方式の改良版を介して「何か言ってください」を直接呼び出す音声認識機能をサポート。

6. **外部音声入力インターフェース** - 音声認識インターフェースを介して「何か言ってください」を呼び出すサードパーティ製アプリケーションをサポート。


### 同期：

1. **複数デバイス対応クリップボード同期** - SyncClipboard を使用すると、クリップボードの内容をあらゆるデバイス間で同期できます。

   
### ユーザーエクスペリエンス：

1. **複数のインターフェーススタイル** - Material-3とMIUIXのスタイルを内蔵。自由に切り替え可能。

2. **複数のインターフェース言語** - アプリケーション内で簡体字中国語、繁体字中国語、英語、日本語の表示をサポート。

3. **キーボード高さ調整** - 3段階の高さ調整が可能。

4. **入力テスト** - 設定画面から直接入力方法をテストできます。

5. **統計機能** - 文字数統計を表示。

6. **振動フィードバック** - マイクボタンを押した際に振動フィードバック。

7. ~~自動更新チェック - 毎日自動的に新バージョンをチェックします。~~ **(パッケージ名とバージョン番号の変更により、元のバージョンと共存できますが、アプリケーションの更新機能は無効になります。)

## 使用方法：

### システム要件：

1. Android 8.0 (API 26) 以降

2. マイク権限（音声認識）

3. フローティングウィンドウ権限（オプション、フローティングボール機能用）

4. アクセシビリティ権限（オプション、自動テキスト挿入用）

### インストール手順：

1. [リリース](https://github.com/qimuan7/SaySomething-Keyboard-Hant/releases) ページから最新バージョンのAPKをダウンロードします。

2. Android端末にインストールします。

### 入力方法の有効化：

> 設定 → システム → 言語と入力 → 仮想キーボード → キーボードの管理 → 「SaySomething」を有効にする

### ASRサービスの設定

1. SaySomethingの設定を開きます。

2. ASRプロバイダーを選択します（推奨：Volcano Engine）

3. APIキーを入力します。

### 使用開始~

1. 「Say」に切り替えます。入力ボックスに「何か」と入力する方法

2. マイクボタンを長押ししてから何か話してください

## 変更点:

#### 直接確認できる項目:

1. ***設定 > 入力設定*** (しきい値を削除するスライダーの下) で、***繁体字中国語出力*** と ***簡体字から繁体字中国語への変換基準*** を追加します (オプションを開いた後にのみ表示されます)。

2. ***設定 > バージョン情報 > アプリケーション*** で、***名前、バージョン番号、パッケージ名*** を変更します。
   
   
#### 変更を行った場合にのみ表示される項目:

1. ***root directory/build.gradle.kts*** の4行目のAGPバージョンを9.1.1に変更します (元は9.4.1です) (もちろん、変更可能です) （ご自身で修正してください）。

2. ***/app/build.gradle.kts*** の28行目にある applicationId = "com.brycewg.asrkb" を "lkg.speechinput.ime" に変更しました。名前空間は変更されていません。

3. ***/app/build.gradle.kts*** の31～32行目にある versionCode と versionName を 500 (500) に変更しました。

4. ***/app/src/mmain/AndroidManiFest.xml*** の6行目と8行目にある .permission の前の元のパッケージ名を、applicationId に動的に追従するように変更しました。

変更2～4は、元のバージョンとの競合を回避し、自動更新によってこのバージョンが上書きされないようにするために行われました。そのため、大きなバージョン番号と異なるパッケージ名が使用されています。

これで、両方のバージョンを同じデバイスに同時にインストールできます。

## 宣言：

**このプロジェクトは、github.com/BryceWG/BiBi-Keyboard の音声入力メソッドのバージョン4.1.2を修正して使用しています。**

**繁体字中国語出力の実装に​​は、github.com/qichuan/android-opencc の OpenCC ライブラリ（S2T、S2HK、S2TWP）を使用しています。**

正直なところ、元のプロジェクトの Pro バージョンは使用したことがありませんし、 「繁体字中国語出力」の実装方法を知りたいです。

私の目的は、オリジナルプロジェクトのPro版を置き換えたり、クラックしたりすることではありません（そもそもそんなことはできません）。

繁体字中国語を使い慣れているユーザーとして、お気に入りのキーボードプロジェクトを、テキスト変換の手間をかけずに、日常生活でより便利に使えるようにしたいと思ったのです。

そこで、このブランチを作成しました。偶然にも、これはオリジナルプロジェクトのPro版の機能リストにも含まれています。

また、オリジナルプロジェクトのPro版は、AI出力に基づいているため、OpenCCを使った私の強制翻訳よりも優れた出力結果が得られるのではないかと考えています。
