# 音声入力 - オフライン音声入力体験の極意

オフラインAIモデルを用いた音声入力方式

[Saysomething](https://github.com/BryceWG/BiBi-Keyboard)の入力方式をベースにしています

[OpenCC](https://github.com/qichuan/android-opencc)を使用して繁体字中国語入力に対応しています

オンライン機能を排除することで、インターネット接続がなくても信頼性の高い音声入力方式を提供します

## 機能:

### 音声認識機能：

- 中国語（北京語、広東語）、地域言語、英語、日本語などに対応。

- 完全オフラインの音声認識モデル。100MBから800MBまでの容量に対応し、高速、高精度、安定、プライバシー保護を実現。

### 入力とインターフェース：

- AI編集パネル：音声コマンドだけでテキストを編集可能。

- ボタンレイアウトをカスタマイズ可能。

- Material-3とMIUIXのインターフェーススタイル。

- 多言語表示：簡体字中国語、繁体字中国語、英語、日本語。

- シンプルな初期設定。

### その他の機能：私は通常の音声入力方法としてのみ使用しています。様々な機能があなたをお待ちしています～

## 使用方法:

### システム:

- Android 8.0 (API 26) 以降

### 権限:

- マイク権限 (音声認識に必須)

- フローティングウィンドウ権限 (フローティングボール機能に任意)

- アクセシビリティ権限 (テキスト自動挿入に任意)

### インストールとアクティベーション:

1. [リリース](https://github.com/qimuan7/SaySomething-Keyboard-Hant/releases) ページから「Spime_**BR1**_vXXX(XXX).apk」バージョンのAPKファイルをダウンロードします。

2. Android端末にインストールします。


3. 初期画面に基づいて権限を取得します：設定 → システム → 言語と入力 → 仮想キーボード → キーボードの管理 → 「音声入力」を有効にする

### モデルのダウンロード：

1. 設定を開きます。

2. お好みの音声認識サービスプロバイダを選択し、モデルサイズを選択して、「ワンクリックダウンロード」をクリックします。

- 手動でダウンロードするには、設定 → 音声認識設定に進み、設定チュートリアルを表示します。すると、オフライン設定ガイドページが表示されます。そこにモデルのダウンロードリンクがあります。または、[Release-ModelDownload]() にダウンロードして保存することもできます。

### 使用方法

- 任意の入力ボックスで「何かを言う」入力方法に切り替え、マイクボタンを長押しして認識を開始します。

## オリジナル版、ブランチ2、および本バージョン（変更内容）の違い：

### [オリジナル版](https://github.com/BryceWG/BiBi-Keyboard)

- 基本機能はすべて搭載

- オリジナル版のアップデートに対応

- 繁体字中国語入力は非対応

- オンラインサービスとオプションのデータ収集機能を搭載

### [ブランチ2（このリポジトリの別ブランチ）](https://github.com/qimuan7/SaySomething-Keyboard-Hant/tree/2)

- オリジナル版と比較して、**機能と内容はすべて同じ**

- **繁体字中国語入力を追加**

- **（チェック）アップデートなし**

- **オリジナル版とは共存可能だが、ブランチ1とは共存不可**

### [ブランチ1（このブランチ）](https://github.com/qimuan7/SaySomething-Keyboard-Hant/)

- 比較オリジナル版から、**モデルダウンロード機能以外は、すべてのオンライン機能を削除しました**（WebDAVバックアップ、匿名データ収集、クリップボード同期、アップデートとアップデート確認、Pro版プロモーションなど）。

- **すべてのオンラインAIサービスプロバイダを非表示にします**（デフォルトでオフラインモデルを使用するように変更し、オリジナルのオンライン設定チュートリアルドキュメントを埋め込みます）。

- 元のプロジェクト名を変更します。**中国語**は**空白**または**「音声入力」**に変更します。**英語**は**空白**または**「音声入力」**に変更します。

- **繁体字中国語入力を追加します**

- **オリジナル版とは共存できますが、ブランチ2とは共存できません**

## 注記：

名前が示すとおり、このブランチではすべてのオンライン機能が削除されています。元の名称は削除されています。これは「個人的なこだわり」によるものであり、すべての人に適しているとは限りません。

元々は私自身の使用目的でコンパイルしたため、多くの奇妙で不要な変更が含まれています。


オンラインアクセスへの不信感から、オンライン機能を削除しました。オフライン時にすべての電話機能が使えなくなるのではないかと心配だったので、これは単なる代替案です。

元のプロジェクト名を削除したのは、盗用や新規プロジェクトの開始を意図したものではありません。「BIBI」という単語がどうしても気になったので、このブランチから削除しました。

オリジナルの体験をしたいけれど繁体字中国語の入力ができない場合は、ブランチ2をお試しください。こちらは繁体字中国語出力のみのオリジナルバージョンです。
