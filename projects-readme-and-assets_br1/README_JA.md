# Speech Input - こだわりのオフライン音声入力体験

オフラインAIモデルを使用した音声入力方式

[Saysomething](https://github.com/BryceWG/BiBi-Keyboard) 入力方式をベースに開発

[OpenCC](https://github.com/qichuan/android-opencc) を使用し、繁体字中国語の入力をサポート

複数のモデルが日本語入力を可能にするから 〜(〜￣▽￣)〜

オンライン機能を排除し、インターネット接続なしでも信頼できる音声入力環境を提供

## 特徴:

### 音声認識:

- 標準中国語（マンダリン）、広東語、各地方言語、英語、日本語などに対応。

- 完全オフラインの音声認識モデル（サイズ：100MB〜800MB）。高速・高精度・安定動作に加え、プライバシーも保護。

### 入力とインターフェース:

- AI編集パネル：音声コマンドだけでテキスト編集が可能。

- カスタマイズ可能なボタン配置。

- Material-3 および MIUIX スタイルのインターフェース。 - 多言語表示：簡体字中国語、繁体字中国語、英語、日本語。

- シンプルな初期設定。

### その他の機能：基本的には通常の音声入力として使用しますが、他にも便利な機能がありますので、ぜひ試してみてください。

## 利用環境：

### システム：

- Android 8.0 (API 26) 以上

### 権限：

- マイクの権限（必須：音声認識用）

- フローティングウィンドウの権限（任意：フローティングボール機能用）

- ユーザー補助（アクセシビリティ）の権限（任意：テキストの自動入力用）

### インストールと有効化：

1. [Releases-Apps & SourceCodes Download](https://github.com/qimuan7/SaySomething-Keyboard-Hant/releases/tag/2.apps%26source-codes) ページから APK ファイル「Spime_**BR1**_vXXX(XXX).apk」をダウンロードします。

2. Android デバイスにインストールします。

3. 初回起動画面の案内に従って権限を設定します：設定 → システム → 言語と入力 → 仮想キーボード → キーボードを管理 → 「Voice Input」を有効にする。

### モデルのダウンロード：

1. 「設定」を開きます。

2. 好みの音声認識サービスプロバイダーとモデルサイズを選択し、「ワンクリックダウンロード」をクリックします。

- 手動でダウンロードする場合は、「設定」→「音声認識設定」から設定ガイドを確認してください。内蔵のオフライン設定ガイドページが表示され、そこからモデルのダウンロードリンクにアクセスするか、[Release-Models Download](https://github.com/qimuan7/SaySomething-Keyboard-Hant/releases/tag/1.model) からダウンロードして保存することができます。

### 使い方：

- 入力欄で「SaySomething」入力メソッドに切り替え、マイクボタンを長押しすると認識が開始されます。 ---

## 備考：

その名の通り、本ブランチはすべてのオンライン機能とオリジナルの名称を削除しています。これは「個人的なこだわり」によるものであり、すべての人に適しているわけではないかもしれません。

私は当初これは個人的な使用のために作成したものであり、一見奇妙で不要に思える変更が多数含まれているのはそのためです。

オンライン機能の削除は、オンラインシステムへの不信感と、オフライン時にすべての機能が使えなくなることへの懸念によるものです。したがって、これは単なる代替版です。

元のプロジェクト名を削除したのは、プロジェクトを盗用したり別のプロジェクトを立ち上げたりする意図ではありません。単に「BIBI」という言葉にネガティブな印象を抱いたため、このブランチから削除しただけです。

もしオリジナルの使用感を維持しつつ繁体字入力を行いたい場合は、ブランチ2を試してみてください。こちらはオリジナルのバージョンに繁体字出力機能を追加しただけの純粋な構成になっています。

## 帰属に関する宣言:

**このプロジェクトは、音声入力方式 `github.com/BryceWG/BiBi-Keyboard` のバージョン4.1.2を改変したものです。**

**このブランチでは、`github.com/qichuan/android-opencc` にあるOpenCCライブラリ（S2T、S2HK、S2TWP）を使用して繁体字出力を実装しています。**

正直なところ、私はオリジナルプロジェクトのPro版を使用したことがなく、Pro版で「繁体字出力」がどのように実装されているのかも知りません。

私の目的は、オリジナルプロジェクトのPro版を置き換えたり、その仕組みを解析したりすることではありません（そもそも私には不可能です）。

ただ、繁体字を頻繁に使用するユーザーとして、お気に入りのキーボードプロジェクトを、テキスト変換の手間なく日常生活でより便利に使いたいと願っていました。

そこでこのブランチを作成しました。偶然にも、これはオリジナルプロジェクトのPro版の機能リストに含まれている機能でもあります。 AIの出力をベースにしている（と思われる）元のプロジェクトの「Pro版」の方が、私がOpenCCを使って無理やり変換したものよりも、優れた出力結果が得られるのではないかと考えています。

もしこの入力方式を気に入っていただけたなら、ぜひ元のプロジェクトを応援・支援していただけると嬉しいです (〃￣︶￣)人(￣︶￣〃)。これほど素晴らしいプロジェクトのスター数が706個にとどまっているのは、本当に残念なことです。
